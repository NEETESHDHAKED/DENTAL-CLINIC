# 🦷 Dental Clinic App

Dental Clinic Management System - Book appointments & manage patients.

## 🚀 Features
- Book Appointment
- Patient Registration
- Doctor Dashboard
- Treatment History
- Appointment Status - Pending / Confirmed

## 🛠️ Tech Stack
- Python
- Flask
- SQLite / JSON
- HTML / CSS / JavaScript
- Bootstrap

## 📦 How to Run
```bash
pip install -r requirements.txt
python app.py
